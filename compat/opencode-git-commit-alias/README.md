# @reachdevel/opencode-git-commit (deprecated)

This package was renamed to [`opencode-git-commit`](https://www.npmjs.com/package/opencode-git-commit).

Version 3.0.0 of this alias re-exports the unscoped package, so existing
installs keep working. New installs should use the unscoped name:

```bash
opencode plugin add opencode-git-commit@latest
```

```json
{
  "plugins": ["opencode-git-commit@latest"]
}
```
